# This repository has moved

As of October 16, 2026, the Home Assistant Data Science Portal lives at **[contributors.home-assistant.io](https://contributors.home-assistant.io/data/)**: one site for everyone who contributes to Home Assistant, code or no code. It replaces data.home-assistant.io, developers.home-assistant.io, and design.home-assistant.io.

- Read the data documentation at [contributors.home-assistant.io/data](https://contributors.home-assistant.io/data/).
- Open issues and pull requests at [home-assistant/contributors.home-assistant.io](https://github.com/home-assistant/contributors.home-assistant.io).

Old links to data.home-assistant.io redirect to their new home.

This repository is kept for its history and is no longer maintained. Changes made here won't be published.
